# starpuzzle-next.js

A Magic Star of David math puzzle. A six-pointed star is drawn with six lines and twelve vertices. Arrange the integers 1 through 12, one on each vertex, so that the four integers on each line add to 26.

Implemented as a React.js interactive web single page application.

Running at [https://atmini.lv](https://atmini.lv)

# Running
To install dependencies, run:

    pnpm install
    
To start dev server, run:

    npm run dev
